# Code of Conduct

## Standard

Be straightforward and civil. Critique work, not people. Assume the other person
is acting in good faith until you have evidence otherwise.

Unacceptable: harassment, personal attacks, discriminatory language, publishing
others' private information, or sustained disruption.

## Scope

Applies in this repository's issues, pull requests, discussions, and any space
where you are representing the project.

## Enforcement

Report concerns to the maintainer via a private GitHub advisory or direct
contact. Reports are handled confidentially. Outcomes range from a private word
to a permanent ban, proportionate to the conduct.

The maintainer is the final arbiter while this project has a single maintainer.
That will change when it has more.
